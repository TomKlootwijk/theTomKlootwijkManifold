# The Tom Klootwijk Manifold package

Target: Unity 6000.3 / URP 17.3.0.

The exact object is the 7-torus `Product S^1(r_i)` embedded in `R^14`. `TKProjectedSlice` displays a 3D linear projection of a periodic 2D slice. `TKManifoldVolume` and its shader are an optional rounded 3D surrogate made from seven capsule fields; they are not the 7D manifold itself.

Use the **GameObject > Tom Klootwijk Manifold** menu after installation.
