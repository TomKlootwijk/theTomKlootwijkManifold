# Source-to-definition mapping

The formal package uses the supplied materials under an explicit evidence discipline. Source phrases are not copied into the core merely because they appear in a dialogue; they enter only after they can be represented as a typed map, field, predicate, event, transition, invariant, bounded profile or measurable implementation quantity.

## SRC-A - UGTS-KC 3.6

Retained directly:

- the world object with an in-substrate definition registry;
- typed content-addressed definition records and dependency closure;
- parametric and implicit geometry with an explicit sign convention;
- exact-SDF status as a capability rather than a synonym for implicit field;
- explicit quotient/gluing, sheet/orientation state and generic hinge tuples;
- support -> compatibility -> guard -> transition -> lineage order;
- the distinction between continuous field morphing and committed topology changes;
- rejection of personal-number causation, zero-cost rendering and topology-as-energy claims.

## SRC-B - named manifold dialogue

Retained after correction or bounding:

- the requested individual name **Tom Klootwijk Manifold**;
- an optional seven-dimensional Euclidean profile for seven mutually orthogonal axes;
- compact procedural definitions as a possible storage strategy;
- parity/LSB state as a route selector;
- fractal offset/regularization as an explicit operation for rounded visual forms.

Not admitted as stated:

- that four coordinates yield seven orthogonal directions;
- that `SDF = 0` automatically defines a sphere or smooths a fractal;
- that LSB indexing changes Hamming distance or performs arbitrary multi-bit mutation;
- that a few symbols imply zero VRAM, infinite detail or constant-time rendering.
